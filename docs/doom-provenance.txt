# Doom Provenance

vibe-os uses the original id Software Doom source release, not Chocolate Doom,
doomgeneric, or a simplified reimplementation.

The vendor tree is `third_party/doom/linuxdoom-1.10`. It should remain
pristine. Platform work belongs in `doom_port/`, the kernel, user runtime, or
build glue outside the vendor tree.

Game data is separate from source code. `DOOM1.WAD` is required to play, but WAD
files are not tracked. The cloud play launcher fetches and validates the public
shareware WAD on the disposable host only.

Allowed in git:

- original Doom source release files,
- local platform layer source,
- build scripts,
- docs,
- tiny generated-free tests and fixtures.

Forbidden in git:

- WAD/IWAD/PWAD files,
- generated disk images,
- VM logs,
- screenshots/framebuffer dumps,
- raw audio captures,
- personal secrets or cloud tokens.

The project should keep proving that Doom builds from the original source while
leaving the source itself untouched.
